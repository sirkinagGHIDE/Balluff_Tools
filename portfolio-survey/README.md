# Portfolio Request survey

Internal survey where sales reps flag product gaps and portfolio requests for review. Reps pick the closest matching product (with a photo), describe the technical requirement, tag competitors and target markets, and give pricing/volume expectations. Submissions log automatically and reps can ping the portfolio owner via email or Teams.

**Live page:** https://claude.ai/artifact/2cDLz7VZY5Uzp1JzMGx1a3

## Files

- `survey.html` — the full page (published as a Claude Artifact; source of truth lives there, this is a mirror for version history)
- `photos/` — product reference photos shown in the picker, named `<product-code>.jpg` (or `<code>-<variant>.jpg` where a code covers more than one product)

## Updating

The live page is published from `survey.html` via the Claude Artifact tool. Edit here, then republish to the same artifact URL to push changes live.
