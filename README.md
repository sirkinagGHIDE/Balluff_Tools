# Balluff_Tools

Sales and marketing tools for Balluff — managed by PMM for PH/PO clusters.

## Tools

- [`portfolio-survey/`](portfolio-survey/) — internal survey for the sales field team to flag product gaps and portfolio requests across the full Balluff portfolio (9 product areas, 57 families). Live at https://sirkinagghide.github.io/Balluff_Tools/portfolio-survey/
- [`distance-sensor-selector/`](distance-sensor-selector/) — draw.io flowchart for picking a photoelectric distance sensor family (BOD 6K, 21M, 23K, 24K, 37M), by distance or by application.
- [`diffuse-sensor-selector/`](diffuse-sensor-selector/) — draw.io flowchart for picking a diffuse photoelectric sensor family (14 BOS families), by housing or range and by application.
